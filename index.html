About Me.

My Journey

I'm a results-driven Front-End Developer and Management Information Systems (MIS) student based in Cairo, Egypt. I specialize in high-performance, responsive web interfaces and dynamic WordPress sites, and I'm highly proficient in React.js, modern JavaScript, UI component libraries and custom Elementor websites.

I use AI tools and prompt engineering to speed up my workflow, tighten layouts and write clean, maintainable code. I'm a fast, proactive learner who enjoys picking up new web standards and stacks. My languages are Arabic (native), English (professional working proficiency) and Spanish (learning).
